# Requirement checklist

Check whether the requirement makes these explicit when relevant:
- user/actor
- trigger
- desired outcome
- inputs and outputs
- source of truth
- state transitions
- permissions/authentication
- validation rules
- error behavior
- retry/idempotency behavior
- data retention/history
- observability/auditability
- performance constraints
- compatibility constraints
- migration/backfill needs
- acceptance criteria
- non-goals
