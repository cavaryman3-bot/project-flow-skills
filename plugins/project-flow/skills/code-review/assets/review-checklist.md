# Review checklist

Check where relevant:
- acceptance criteria mapping
- null/empty/malformed input
- boundary values
- duplicate/replayed requests
- partial failure
- transactional consistency
- race conditions
- authorization boundary
- sensitive logging
- stale/cached data behavior
- migration compatibility
- rollback safety
- pagination/limits
- timezones/date boundaries
- test assertions vs mere execution
- feature flag/default behavior
